# MONOMOD

**Один интерфейс, модифицированный под тебя.** MONOMOD — это одна страница, которая перестраивается под каждого человека: один адрес, и у каждого своя версия.

🔗 Сайт: https://ekhusyainova-blip.github.io/monomod/

## Что внутри
- **Онбординг из 3 вопросов:** имя, главная цель, любимый цвет (6 готовых + свой).
- **Персональный экран:** приветствие по времени суток, фокус дня под цель, прогресс к цели (+1, отметка «сделано сегодня», серия дней), мысль дня, время и дата, погода рядом (Open-Meteo, только с разрешения на геолокацию).
- **Правила персонализации:** порядок модулей меняется по времени суток и по тому, сделан ли шаг сегодня; советы дня подбираются по теме цели (языки, спорт, код, чтение, финансы).
- **«Поделиться моей версией»:** профиль кодируется в ссылку `?u=…`, и по ней сразу открывается эта версия.
- **Тема:** светлая днём и тёмная вечером автоматически, плюс ручной переключатель.

## Приватность
Без сервера и регистрации: профиль и прогресс хранятся только в `localStorage` браузера.

## Технологии
Чистые HTML, CSS и JS без сборки. Хостинг на GitHub Pages.
