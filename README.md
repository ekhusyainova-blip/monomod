# MONOMOD · канон v12.0

Сайт: **https://ekhusyainova-blip.github.io/monomod/**

```
MONOMOD = GIT ∘ K ∘ ВОЗВРАТ ∘ argmax S ∘ M# + 110.347
        = K + p1..p10
```

Репозиторий хранит канон MONOMOD v12.0 — 32 one-page спеки — и статический сайт, который строится по этому канону.

## Что на сайте

- **Канон ONE PAGE v12.0** — формула, иерархия `𝕄_full ⊃ 𝕄+ ⊃ 𝕄++ ⊃ MONOMOD`, CORE, 5 мод, сценарии S1–S9 и X1–X4, ветки D1–D3, правило двух держателей, инвариант.
- **Граф зависимостей** — узлы кликабельны: открывается спека, ниже по графу подсвечиваются зависимые узлы и соответствующее правило зависимостей.
- **32 файла** — браузер спек по слоям (CORE, 𝕄_full, 𝕄+, 𝕄++, моды, UX, инфраструктура); markdown подгружается из `specs/` прямо в браузере.
- **Два держателя баланса** — «Страж K» и «Страж S», матрица ответственности, правило баланса.
- **Проверка баланса (S3)** — вводишь K и p1..p10, страница сравнивает сумму с 110.347; при расхождении показывает состояние `X4 → ВОЗВРАТ`. Канон не задаёт значения K и p1..p10, поэтому поля пустые.


## Правила зависимостей

- Изменение в 01-core → пересчёт всех 32 файлов
- Изменение в 02-k или 03-p* → триггер 04-110.347 → возможен X4
- Изменение в 05/06/07 (границы) → пересборка мод M4
- Изменение в 13-formula → только через D3 с двумя подписями

## Примечания

- Файл `03-p1..p10.md` из канона хранится как `specs/03-p1-p10.md`.
- Файлы 27, 29 содержат шаблоны журналов (записей пока нет); 28 — роли держателей, правило баланса, матрицу и шаблон журнала подписей; 32 — карту v1.0 → v12.0, где v12.0 = канон.
