    Правило баланса (канон)

    1. Ни одно изменение K или p1..p10 не вступает в силу без двух подписей.
    2. При расхождении K + p1..p10 ≠ 110.347:
      • оба держателя уведомляются одновременно
      • активируется X4
      • система блокируется до отката
    3. При конфликте держателей:
      • приоритет у Держателя #1 по K
      • приоритет у Держателя #2 по S
      • при взаимном veto → стоп + эскалация
    4. Смена держателя:
      • только с согласия второго
      • запись в 28-log-control.md
